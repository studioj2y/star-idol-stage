# ★ STAR IDOL STAGE! (星のアイドルステージ) ★

> **なぁたん Live Stage Edition (Red Gingham Live Concert Edition)**  
> 一款复古街机像素风格的垂直平台跳跃网页游戏。操控身着红白格子打歌服的元气偶像「なぁたん」，在演唱会舞台与浩瀚星空之间纵情起跳，收集星光、触发 **IDOL FEVER**，引爆全场「もっと！」「なぁたん！」的现场打 Call！

## ✨ 核心特色 (Features)

1. **红白格子舞台打歌服 & 元气偶像「なぁたん」**
   - **动态惯性高马尾**：伴随移动与跳跃具有物理飘动效果，发根系着红白格子蝴蝶结大发饰。
   - **层叠荷叶边泡泡袖 & 蕾丝系带**：红白野餐格子（Gingham Check）露腰打歌服，搭配白蕾丝交叉系带与舞台短靴。
   - **招牌指天动作（☝）与手持麦克风**：跃向星空时指尖闪耀星光，手持专业舞台麦克风开怀欢唱。
   - **二段翻滚跳跃（Somersault）**：二段跳触发华丽 360° 空中旋转，拖曳出彩虹微光粒子。

2. **现场打 Call 与人声合成（Call & Response）**
   - **Web Audio 双共振峰人声合成**：完全自制合成器，台下粉丝会齐声喊出专属打 Call 声：
     - *「もっと！もっと！（motto! motto!）」*
     - *「なぁたん！（naatan!）」*
   - **观众席应援弹幕气泡**：底部挥舞荧光棒的观众席会不断冒出应援气泡（*「超絶可愛い！なぁたん！」「大好きー！」「L・O・V・E なぁたん！」*）。
   - **全场荧光棒联动**：进入狂热模式时全场荧光棒同步加速挥舞并切换为专属红白应援色！

3. **狂热模式与丰富机关**
   - **IDOL FEVER**：收集彩虹心触发全屏狂热状态，获得速度提升、无敌光环、2倍得分与星光磁吸效果！
   - **多样化跳台**：经典霓虹跳台、横向移动平台、一跃冲天的弹簧板、易碎的云朵薄台。
   - **三心生命与拍立得（チェキ）结算**：失误跌落触发复活云朵救赎；演唱会落幕时生成附带亲笔签名与印章的拍立得照片！

## 🕹️ 游戏操作 (Controls)

| 操作动作 | 键盘按键 | 移动端 / 鼠标 |
| :--- | :--- | :--- |
| **左右移动** | `A` / `D` 或 `←` / `→` | 屏幕左下方 `◀` / `▶` 按钮 |
| **起跳 / 二段翻转跳** | `Space` / `W` / `↑` | 屏幕右下方 `★` 按钮 |
| **快速下落 (Fast Fall)**| `S` 或 `↓` | - |
| **暂停游戏** | `P` 或 `Esc` | - |
| **开关声音** | `M` | 屏幕右下方声音按钮 |

## 🚀 本地运行 (Local Run)

无需安装 Node.js 或任何构建工具：
1. 直接双击打开 `index.html`，即可在任意现代浏览器中运行。
2. 或通过 Python 启动简易服务器：
   ```bash
   python -m http.server 8080
   ```
   随后在浏览器访问 `http://localhost:8080` 即可畅玩！
