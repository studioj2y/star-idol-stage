# ★ STAR IDOL STAGE! (星のアイドルステージ) ★

> **なぁたん 世界巡演 · LIVE TOUR EDITION**  
> 一款复古街机像素风格的垂直平台跳跃网页游戏。操控身着红白格子打歌服的元气偶像「なぁたん」，从**东京、大阪**起跑，巡演**巴黎、纽约**，最终登上**银河终点大舞台**！收集星星在偶像衣橱兑换电吉他、星光魔法棒与萌萌猫耳，每站通关生成专属 16-bit 像素风拍立得照片！

## ✨ 核心特色 (Features)

1. **巡演关卡制 (City Tour Progression)**
   - **Stage 1: 東京 · 渋谷 (Tokyo Shibuya Live - 500m)**：东京铁塔与晴空塔霓虹剪影。
   - **Stage 2: 大阪 · 道頓堀 (Osaka Dotonbori Fes - 650m)**：通天阁与繁华道顿堀灯牌。
   - **Stage 3: パリ · エッフェル塔 (Paris Eiffel Tower - 800m)**：暮色下的浪漫埃菲尔铁塔与屋顶剪影。
   - **Stage 4: ニューヨーク · Broadway (New York Broadway - 950m)**：帝国大厦与百老汇霓虹招牌。
   - **Stage 5: 銀河終点大舞台 (The Grand Cosmic Climax - 1200m)**：极光与宇宙行星环绕的终极大舞台！

2. **红白格子打歌服 & 16-bit 像素风拍立得 (Pixel Art Cheki)**
   - 每关通关或落幕时，自绘生成专属的 **16-bit 像素艺术拍立得照片**！
   - 细致还原栗棕色侧高马尾、红白野餐格子大蝴蝶结、双肩荷叶边泡泡袖、眼角细闪贴纸与手持麦克风。
   - 盖有金色烫金印章 **`TOUR CLEAR 🏆`** 与亲笔手写签名 *「なぁたん ♡」*！

3. **偶像衣橱与饰品商城 (Wardrobe & Accessories)**
   - 通关报酬与关卡收集的星币可直接在商店兑换：
     - 🎸 **摇滚电吉他 (Guitar)**：帅气樱桃红电吉他，角色手持弹奏。
     - 🪄 **星光魔法棒 (Wand)**：散发微光的魔法杖，扩大星光吸附范围。
     - 🐱 **萌萌偶像猫耳 (Cat Ears)**：头顶俏皮小猫耳。
     - 👑 **璀璨星光王冠 (Crown)**：巡演女王金色皇冠。
     - 🪽 **常驻天使羽翼 (Angel Wings)**：直接获得常驻三段跳跃能力！

4. **现场打 Call 与人声合成 (Call & Response)**
   - **Web Audio 双共振峰人声合成**：完全自制合成器，粉丝现场打 Call：
     - *「もっと！もっと！（motto! motto!）」*
     - *「なぁたん！（naatan!）」*
   - **观众席应援弹幕气泡**：底部挥舞荧光棒的观众席会不断冒出应援气泡（*「超絶可愛い！なぁたん！」「大好きー！」「L・O・V・E なぁたん！」*）。

## 🕹️ 游戏操作 (Controls)

| 操作动作 | 键盘按键 | 移动端 / 鼠标 |
| :--- | :--- | :--- |
| **左右移动** | `A` / `D` 或 `←` / `→` | 屏幕左下方 `◀` / `▶` 按钮 |
| **起跳 / 二段翻转跳** | `Space` / `W` / `↑` | 屏幕右下方 `★` 按钮 |
| **快速下落 (Fast Fall)**| `S` 或 `↓` | - |
| **暂停游戏** | `P` 或 `Esc` | - |
| **开关声音** | `M` | 屏幕右下方音效按钮 |
| **偶像衣橱商店** | 点击右下方 `🛍️` 图标 | 点击右上/右下 `🛍️` 按钮 |

## 📂 项目结构 (Structure)

```text
├── index.html        # 游戏主页面、HUD 界面、拍立得结算与衣橱弹窗
├── style.css         # 复古街机扫描线、霓虹主题与拍立得质感样式
├── stages.js         # 巡演城市关卡设定与东京/大阪/巴黎/纽约/银河地标背景渲染
├── cheki_art.js      # 16-bit 像素风「なぁたん」拍立得照片自绘引擎
├── shop.js           # 偶像衣橱饰品商城系统（电吉他、魔法棒、猫耳、翅膀）
├── player.js         # なぁたん 角色物理系统、发型惯性与打歌服/装备绘制
├── game.js           # 巡演关卡进度、终点大舞台生成、碰撞检测与打 Call 弹幕
├── audio.js          # Web Audio 8-bit BGM 芯片音乐与人声共振峰合成器
└── README.md         # 项目文档说明
```

## 🚀 本地运行 (Local Run)

无需安装 Node.js 或任何构建工具：
1. 直接双击打开 `index.html`，即可在任意现代浏览器中运行。
2. 或通过 Python 启动简易服务器：
   ```bash
   python -m http.server 8080
   ```
